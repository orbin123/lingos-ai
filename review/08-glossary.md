# 8. Glossary

**Agent** — a prompt/model collaborator with a focused job, such as evaluation or feedback.

**Archetype** — a stable activity kind, its widget identity, supported skills, rubric, and contract.

**Embedding** — a semantic numeric representation of text used for similarity search.

**LangChain** — model/prompt/structured-output abstractions used to build AI calls.

**LangGraph** — a stateful graph of nodes and edges for explicit multi-step workflows.

**LLM** — large language model; useful but probabilistic text reasoning/generation.

**RAG** — Retrieval-Augmented Generation: retrieve relevant records, then provide them as model context.

**Repository** — backend layer containing database queries.

**Service** — backend layer containing business logic and transaction boundaries.

**Streak** — consecutive activity tracking used by the learner dashboard.

**TanStack Query** — frontend server-state cache and synchronization library.

**Zustand** — frontend client-state store library.

**Pydantic schema** — runtime validation and serialization contract for Python data.
